# Stage 04 — Candidate UI V0.1 → V0.2 Comparison & Reviewer Findings

**Date:** 2026-11-21 · **Stage04 visual revision only. D04-UI-007 remains PENDING.**

| Aspect | V0.1 (archived candidate) | V0.2 redesigned candidate | Rationale / test owed |
|---|---|---|---|
| Overall look | Teal/blue feature panels, large tinted cards | Mostly white/near-white, quiet teal and ink | Reduces competing emphasis; preference needs user feedback |
| Home task choices | Large colored blocks with prominent pictograms | Two clear text-led choice rows with minimal directional affordance | Same signed equal-entry intent U1-A, reduced icon weight |
| Navigation | Three labeled nav items | Three labeled nav items, same IA-A | Retain research-approved direction, no new destinations |
| Reading | White passage framed in a card, large colored CTA | Larger content-forward passage, restrained tab bar and one next CTA | Semantic anchor promised in UX, not technically proven |
| Mock | Multiple colored notification areas | One quiet timing panel and state text, policy separated | Must not falsely claim durable save or allow pause/replay |
| Feedback | Teal/blue surfaces around explanation | Neutral answer area, one small verified explanation block | Correct/wrong state requires semantic wording; not red/green only |
| Palette | Teal + mock-blue feature emphasis | Single deep teal accent + neutral ink/surfaces; status only secondary | Less simultaneous hue competition |
| Typography | Proposed font family TBD, 28/24/18/16/14/12 | Single Vietnamese-safe family candidate, 28/22/18/16/14 | Font decision still candidate, no live font scaling tested |
| Excess decoration | More outlined controls, card fills/icons | Avoid duplicated icons and unnecessary cards | Enforce UI-G01..16 checklist |
| Evidence | Image + 31-page old UX clickthrough PDF | Image + source ledger/guardrails/side-by-side review; old clickthrough unchanged | Neither version is a real device screenshot, usability pass or test result |

## Review disposition

**ANALYST RECOMMENDATION:** V0.2 offers a calmer visual starting point better matched to TOEIC reading and long exam use. This remains a *judgment based on design rationale and desk inspection*, not a measured superiority claim. Product Owner must separately approve V0.2 as a controlled design baseline, amend, request short usability testing or HOLD. V0.1 is retained in archive; do not overwrite signed Requirements.
