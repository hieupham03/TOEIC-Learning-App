# UX04 V0.2 — Nine Scenario Routes and Verification Gaps

**Scenarios in a paper/PDF prototype are NOT completed real-user tests.** Each is represented by one clickable example; links are simulators of future navigation only.

| Scenario | Route in candidate PDF | Later evidence required |
|---|---|---|
| SC-01 Find 5-minute practice | INTRO → HOME → PART → PRACTICE | Real learner can find without help |
| SC-02 Choose Full Mock and understand rules | HOME → MOCKS → RULES → LISTEN | Understand no pause/replay and total time |
| SC-03 Read long Part 7 | LISTEN → PASSAGE → READ_Q → ANCHOR → READ_Q | Context-return, actual scroll, font, focus |
| SC-04 Save confirmed versus uncertain | PRACTICE → SAVE_WAIT → SAVED or SAVE_UNCERTAIN → PRACTICE_RETRY | Genuine app durability and truthful display |
| SC-05 Interrupted/invalid exam | LISTEN → INTERRUPT → INT_STATUS → INVALID | Clearly distinguish incomplete vs not comparable; real time behavior |
| SC-06 Report mock raw scores | LISTEN → RESULTS → PROGRESS | Understand 130/200 is hypothetical raw, no ETS equivalence |
| SC-07 Eligible feedback and next practice | PRACTICE → SAVED → FEEDBACK → PRACTICE | No answer leak during clean mock; vetted explanations |
| SC-08 Family privacy and content unavailable | HOME → PRIVACY; MOCKS → UNAVAILABLE | Real data isolation & content gating |
| SC-09 Comparator and two illustrative sizes | INTRO → ALTiA → ALT_READ; INTRO → LARGEPASS → LARGEQ | Controlled comparison and real two-device QA later |

**Unperformed:** any real-user (`n=0`), two physical Android device session, actual Full Mock, QA01..08 content/software tests. Any request to do a short user walkthrough is a future, targeted option, not an implicit condition to accept this desk review.
