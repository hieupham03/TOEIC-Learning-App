- Record **SOURCE-SPECIFIC REUSE RIGHTS: AFFIRMED BY PO** for the three nominated sites (question, audio and image use in a shared Android app, per the immediately preceding direct question).
- Do not continue asking PO to affirm the same right. A future **single batched rights/provenance audit** may reconcile rights holder, covered assets, permission to export/cache/redistribute, time/territory/pilot vs public release, and site automation or access restrictions. - No bulk extraction, automated scraping, credential use, vendor contact, code, architecture, UI or purchases authorized by this decision.
